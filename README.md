# Lan Li — Academic Pedigree

A web view of Lan Li's PhD academic ancestry, graduating from the iSchool
at the University of Illinois Urbana-Champaign in May 2026.

→ **Live page**: <https://ludaesch.github.io/lan-li-pedigree/>

Pinch / scroll to zoom, drag to pan, tap any scholar to open their
Wikipedia / Google Scholar / DBLP page.

Sources and the build pipeline live in a private repo (Math Genealogy
Project data + curated enrichment).
